TPGPT v0.1.1 adds a native home screen and interactive answers with a white-and-blue theme inspired by TrainingPeaks.

- Weekly training time, distance, recorded TSS, active days, sport filters, and eight-week charts.
- Recent workouts and workout details with notes, recorded heart-rate/speed graphs, and laps when available.
- Interactive charts and workout links in assistant answers. Select a chart period to draft a follow-up in the same conversation for review before sending.
- Data freshness, missing TSS coverage, and potentially repeated record notices.
- Improved conversation navigation and layouts for smaller windows.
- A prominent README privacy note explaining local storage, TrainingPeaks token handling, and cloud assistant data sharing.

TrainingPeaks remains read-only. TPGPT never sends its login password or access token to the AI provider; authenticated login and export requests send them to TrainingPeaks itself. Imported history and app conversations are stored locally, while prompts and training context retrieved during chat are sent to your chosen assistant provider.

Download the `.deb` for Ubuntu/Debian or the `.tar.gz` for compatible Linux distributions. Windows uses the portable `.zip`; macOS has separate Apple Silicon and Intel `.dmg`/`.zip` bundles. Install and sign in to Codex or Claude Code separately. See the README for runtime dependencies and setup.

Windows builds are unsigned. macOS bundles are ad-hoc signed without Apple notarization. Platform CI checks formatting, linting, native tests, and the MCP protocol. The UI and live Codex session resumption were verified on Linux using synthetic data. Private account data and credentials are excluded from source and bundles.

`SHA256SUMS` contains checksums for all bundles.
