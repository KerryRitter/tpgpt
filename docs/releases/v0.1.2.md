TPGPT v0.1.2 fixes chat replies extending past the right edge of the window.

- Replies wrap inside the reading column, including Markdown lists and tables.
- A layout regression check covers consecutive replies and resizing between compact and wide windows.
- The README includes the two overview and chat screenshots selected for publication. The publication audit allows only those exact image files, with pinned SHA-256 hashes; app bundles do not include screenshots.

TrainingPeaks remains read-only. Imported history and app conversations are stored locally. Your TrainingPeaks password and access token are never passed to an AI provider; prompts and training context used in chat are sent to your chosen Codex or Claude provider.

Download the `.deb` for Ubuntu/Debian or the `.tar.gz` for compatible Linux distributions. Windows uses the portable `.zip`; macOS has separate Apple Silicon and Intel `.dmg`/`.zip` bundles. Install and sign in to Codex or Claude Code separately. See the README for runtime dependencies and setup.

Windows builds are unsigned. macOS bundles are ad-hoc signed without Apple notarization. `SHA256SUMS` contains checksums for all bundles.
