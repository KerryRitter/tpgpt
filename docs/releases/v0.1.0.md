TPGPT is a native Rust desktop app for importing your TrainingPeaks history into local SQLite and chatting with it through an installed Codex or Claude Code CLI.

- TrainingPeaks login, resumable workout/activity import, and local training analytics.
- Native Markdown chat, saved conversations, provider session resumption, and cancellation.
- Codex/Claude installation checks, setup guidance, and links to official installation docs.

Download the `.deb` for Ubuntu/Debian or the `.tar.gz` for other compatible Linux distributions. Windows uses the portable `.zip`; macOS has separate Apple Silicon and Intel `.dmg`/`.zip` bundles.

Install and sign in to Codex or Claude Code separately. Linux requires GTK 3 and WebKitGTK 4.1; Windows requires WebView2. See the repository README for installation steps.

These builds are unsigned on Windows and ad-hoc signed on macOS, without Apple notarization. Platform CI checks compilation, unit tests, and the MCP protocol; interactive TrainingPeaks login and chat have been verified on Linux. Private account data and credentials are excluded. Requested training context is sent to the assistant provider when you chat.

`SHA256SUMS` contains checksums for all bundles.
